# GPTImage 界面风格

ChatGPT2API 用户界面采用深色控制台风格：黑灰底色、冷灰边框、琥珀黄色强调、紧凑侧栏和低圆角组件。默认深色，保留用户手动切换浅色的偏好。

覆盖登录、图片生成、账号池、图片管理、日志、调试、设置及公共弹窗控件。移动端使用抽屉导航；大屏固定侧栏，主内容不会遮挡导航。保留原有身份验证、管理员权限、第三方跳转确认、图片任务和额度逻辑。

业务标题、统计口径和模型名称仍来自现有功能及接口，不引入示例参考图中的视频、音乐、显存或虚构设备状态。Sub2API 独立管理后台仍使用其上游界面。

主要入口：`sources/chatgpt2api/web/src/app/globals.css`（主题及公共样式）、`components/app-shell.tsx`（布局）、`components/top-nav.tsx`（导航）、`components/theme-script.tsx`（默认主题）。

修改界面后执行 TypeScript 检查和前端构建；预览用测试数据与真实账号完全分离，不把演示数据接入生产。

管理员生图页面已移除顶部生图状态信息面板，释放对话与图片展示空间。仅移除页面入口，保留状态聚合后端和现有业务额度逻辑。
