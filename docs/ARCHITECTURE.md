# 架构与数据流

## 服务职责

| 组件 | 职责 | 数据 | 默认端口 |
|---|---|---|---|
| ChatGPT2API | 网页、异步任务、子账号额度、图片管理、状态聚合 | JSON、SQLite、图片 | 宿主机回环 3000 → 容器 80 |
| Sub2API | API 网关、上游 OAuth 账号池、调度、分组与密钥 | PostgreSQL、Redis、配置目录 | 宿主机回环 8080 → 容器 8080 |
| PostgreSQL 18 | Sub2API 持久数据 | Docker 命名卷 | 不向宿主机发布 |
| Redis 8 | Sub2API 缓存和运行协调 | Docker 命名卷 | 不向宿主机发布 |
| Infinite Canvas（可选） | 浏览器画布、调用 ChatGPT2API | 浏览器本地存储 / IndexedDB，无服务端同步 | 宿主机回环 3002 → 容器 3000 |
| Nginx（可选，宿主机） | TLS 和外部入口 | 自行申请的证书 | 443；可自行增加 8443 |

`ai` 网络连接两个应用并允许上游出站；`database` 内部网络仅连接 Sub2API、PostgreSQL、Redis。ChatGPT2API 不直接访问 Sub2API 数据库。

## 图片请求

1. 网页提交异步图片任务，或客户端调用标准图片接口。
2. ChatGPT2API 验证调用身份、业务额度和并发；有限额度先预留，完成后结算。
3. 接入适配器读取 `IMAGE_UPSTREAM_CONFIG` 指向的私有配置。
4. 文生图以 JSON、编辑以 multipart 请求内部 Sub2API；专用 API 密钥决定可使用的分组。
5. Sub2API 调度账号并向上游发起请求；返回 Base64 图片。
6. ChatGPT2API 调用原有 ImageStorageService 保存原图、更新图片索引；图片管理据此读取列表和生成缩略图。
7. URL 模式返回图片地址，异步任务将可恢复 URL 写入任务数据库；Base64 API 返回原图片编码。

仅经过本适配器的图片进入本项目归档。绕过 ChatGPT2API 直接调用 Sub2API，不会自动同步到图片管理。原生 Responses 的完成响应也会归档其中的图片生成输出；不含图片的文本响应不会产生图库项目。

## 账号信息和状态面板

生成转发使用专用 API 密钥；账户状态查询使用 ChatGPT2API 中保存的 Sub2API 管理连接。二者用途不同，不可互相替代。内部地址要保持一致。

状态面板读取 ChatGPT2API 自己的任务数据库，并查询所配置密钥所属分组的账户状态。上游接口不兼容、缺少管理连接或 key_id 不正确时显示账户池状态不可获取，不影响已正确配置的标准图片转发。

统计口径：当日以北京时间为界；最近 24 小时内最多 20 个终态任务用于成功率；成功任务耗时中位数包含排队时间；30 分钟内有终态结果才显示最近成功或失败，否则为尚未验证。只统计 ChatGPT2API 图片任务，不包含直接调用 Sub2API 的流量。

## 三种“额度”

| 概念 | 来源 | 解释 |
|---|---|---|
| 子账号业务额度 | ChatGPT2API 管理员 | 文本次数、图片张数；可无限制 |
| Codex 使用窗口 | Sub2API 保存的上游快照 | 5 小时/7 天使用比例；可能过期 |
| 生图剩余张数 | 上游是否明确提供 | 当前无法可靠获得时显示未知 |

这三者不能相互换算。冷却时间也不能等同于剩余额度。新账号默认无限制，迁移前已有零额度仍为零，不会被自动放开；并发限制始终独立生效。

## 统一路由与画布

默认 `SUB2API_ONLY=1`：文本、Responses、Messages、模型列表与搜索通过 Sub2API；网页客户端被阻止创建，无对应接口的 PPT/PSD 等能力返回不支持。详情见 [路由表](SUB2API-ROUTING.md)。

配置 `IMAGE_UPSTREAM_CONFIG` 后，标准生成、编辑和后台任务绕过旧账号调度器，这一条件独立于严格模式，避免画布请求被旧调度器抢先送入网页接口。

画布是可选独立 origin 的静态前端，请求由用户浏览器直接送到 ChatGPT2API 的公开地址。它不访问 Sub2API 数据库，不持有 Sub2API 专用上游密钥。浏览器本地画布数据与服务器图片归档是两种不同存储；详见 [画布部署](INFINITE-CANVAS.md)。管理员生图页已移除顶部状态面板，但状态聚合后端保留。
